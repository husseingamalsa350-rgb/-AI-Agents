# AgentTeam

تطبيق محادثة محلي تبني فيه فريقًا من الـ AI Agents: كل Agent له اسم وشخصية وموديل ومساحة عمل خاصة، وتكلمه كأنه جهة اتصال في تطبيق شات.

نسخة مبدئية (prototype) مستوحاة من فكرة تطبيقات "فريق الـ Agents"، مكتوبة من الصفر وغير تابعة لأي مشروع أو شركة أخرى.

## التشغيل

يحتاج Node.js 18 أو أحدث فقط، بدون أي dependencies:

```bash
node server.js
# ثم افتح http://localhost:4747
```

## المميزات

- **Agents في الـ Sidebar**: لكل واحد أيقونة واسم وشخصية (persona) و provider وموديل، وتقدر تضيف وتعدّل وتحذف.
- **بيستخدم الـ CLI اللي عندك**: التطبيق يشغّل `claude` أو `codex` أو `grok` المثبتين على جهازك بتسجيل الدخول والاشتراك بتاعك. مفيش proxy ولا API keys داخل التطبيق.
- **ذاكرة لكل محادثة**: آخر 40 رسالة من الـ thread بتتبعت للموديل مع كل رد، والمحادثات محفوظة في `data/state.json`.
- **Approval Cards**: لما Agent يحب يشغّل أمر shell بيظهر لك كارت بالأمر، ومش بيتنفذ غير بعد ما تضغط *Approve & run*. الناتج بيرجع للـ Agent عشان يكمل.
- **مساحة عمل لكل Agent**: الأوامر بتتنفذ داخل `data/workspaces/<agent-id>/`.
- **Channels**: محادثة جماعية فيها أكتر من Agent. اكتب `@Name` عشان توجه الكلام لواحد بعينه، ومن غير mention الكل بيرد بالترتيب. والـ Agent يقدر يعمل `@mention` لزميله عشان يسلّمه الشغل.
- **وضع Demo**: لو مفيش أي CLI مثبت، الـ Agents بتشتغل بـ provider تجريبي. جرّب `run: ls -la` عشان تشوف دورة الموافقة.

## الـ Providers

| Provider | الأمر اللي بيتشغل |
| --- | --- |
| `claude` | `claude -p [--model M]` (الـ prompt على stdin) |
| `codex` | `codex exec --skip-git-repo-check [-m M] -` (الـ prompt على stdin) |
| `grok` | `grok -p "<prompt>" [-m M]` |
| `demo` | رد تجريبي بدون موديل |

سيب خانة Model فاضية عشان تستخدم الموديل الافتراضي للـ CLI.

تم اختبار `claude` فعليًا. صيغة `codex` و `grok` لم تُختبر هنا، ولو الـ CLI عندك بيستخدم flags مختلفة عدّلها (أو أضف provider جديد) في `data/providers.json`:

```json
{
  "grok": { "cmd": "grok", "args": ["-p", "{prompt}"], "modelArgs": ["-m", "{model}"], "stdin": false }
}
```

## الأمان — اقرأ قبل الاستخدام

- الأوامر اللي بتوافق عليها بتتنفذ **بصلاحيات المستخدم بتاعك على جهازك مباشرة**. مساحة العمل مجرد مجلد البداية، مش sandbox. راجع كل أمر قبل الموافقة.
- كروت الموافقة بتغطي الأوامر المطلوبة عن طريق التطبيق. الـ CLI نفسه (Claude Code / Codex) له أدواته وصلاحياته الخاصة حسب إعداداتك، فلو مفعّل فيه وضع بيتخطى الصلاحيات هيشتغل بيه.
- السيرفر بيسمع على `127.0.0.1` فقط، وبيرفض طلبات الـ cross-origin والـ Host الغريب.
- **مفيش authentication**. لو شغّلته بـ `HOST=0.0.0.0` أي حد يوصل للبورت يقدر يوافق على أوامر. للوصول من جهاز تاني استخدم SSH tunnel أو VPN.

## الإعدادات

| متغير | الافتراضي | الوظيفة |
| --- | --- | --- |
| `PORT` | `4747` | بورت السيرفر |
| `HOST` | `127.0.0.1` | عنوان الاستماع |
| `AGENT_TEAM_DATA` | `./data` | مكان حفظ المحادثات ومساحات العمل |

## غير موجود بعد

Tasks، ربط التطبيقات الخارجية، تشغيل الـ Agent على VM أو Cloud computer، التحكم في المتصفح/سطح المكتب، streaming للردود، وتطبيقات Desktop.
